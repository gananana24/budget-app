# 家計簿アプリ MVP要件

更新日: 2026-09-23

## 目的と利用者

- 毎月、何にいくら使ったかを把握し、予算内に収めることを助ける。
- 初期の主な利用者は本人。公開後は、Googleアカウントを持つ他の利用者も登録できる。
- 利用者ごとの支出・費目・予算は分離し、他の利用者には見せない。
- 家族による利用は将来想定するが、家計簿や予算の共有はMVPに含めない。
- 課金と広告は導入しない。

## 提供形態

- iPhoneとAndroidのスマートフォンで使うWebアプリとして公開する。
- ホーム画面からアプリのように開けるPWAにする。PC向け画面はMVPの対象外。
- 利用にはオンライン接続を必要とする。オフラインでの支出登録は対象外。
- Googleアカウントでログインする。他のログイン方法はMVPでは提供しない。
- アカウントにデータを紐づけ、機種変更後も引き継げるようにする。
- 画面表示は日本語のみ。文言は多言語対応の仕組みで一元管理する。
- 通貨は日本円のみとし、金額は1円単位で扱う。
- 「今日」と「今月」は日本時間を基準にする。

## 支出の記録

- MVPで記録する取引は支出のみ。登録方法は手入力。
- 必須項目は日付・金額。費目とメモは任意。
- 支出額は1円から2,147,483,647円まで入力できる。
- メモは前後の空白を取り除いて保存し、500文字まで入力できる。空白だけの場合はメモなしとして扱う。
- 過去の日付で登録でき、支出はその日付が属する月に集計する。未来の日付では登録できない。
- 支出日の最古日は制限しない。有効な日付形式で、日本時間の今日以前なら登録できる。
- 同じ日・金額・費目の支出も複数登録できる。
- 費目を選ばずに登録した支出は「未分類」として表示する。編集時に費目を設定したり、設定済みの費目を未分類へ戻したりできる。
- 登録済みの支出は、過去月のものも含めて修正・削除できる。
- 非表示の費目が付いた既存の支出も、費目を維持したまま日付・金額・メモを修正できる。費目を変更する場合は表示中の費目から選ぶ。
- 修正前の内容を履歴として保存・表示する機能はMVPに含めない。
- 支出の削除前には確認を求める。削除した支出は集計やCSV書き出しの対象から外れる。
- 支払方法は記録しない。返金は独立した取引としては記録せず、元の支出の修正・削除で対応する。
- 家賃やサブスクなどの定期支出もMVPでは手入力する。

## 費目

- 初期費目は「食費」「日用品」「住居費」「水道光熱費」「通信費」「交通費」「医療費」「娯楽費」「その他」の9つ。
- 利用者は費目を追加し、名前を変更できる。
- 新しく追加した費目は、その費目を作る前の日付の支出にも使用できる。
- 費目名は前後の空白を取り除いて保存し、1〜50文字とする。空白だけの名前は使えない。
- 同じ家計の中では、初期費目と追加した費目を通じて同じ名前を使えない。別々の家計では同じ費目名を使える。
- 英字の大文字・小文字だけが違う費目名も、同じ家計内では同名として扱う。表示上の表記は入力どおり残す。
- 使わなくなった費目は新しい支出の入力候補から外せる。過去の支出と費目名は残す。
- MVPでは費目を個別に削除しない。誤って追加した未使用の費目も非表示にして管理する。
- 非表示にした費目は再表示できる。
- すべての費目を非表示にしてもよい。表示中の費目がなくても、支出は未分類として登録できる。
- 費目は初期の9件を記載順で表示し、追加した費目は追加順に続ける。名前変更や再表示で順番は変えず、MVPでは手動で並べ替えられない。
- 費目名を変更すると、過去の支出に表示される名前も変わる。

## 予算と集計

- 予算期間は暦月の1日から末日まで。費目ごとに月の予算額を設定する。
- 初期費目の予算額はすべて未設定。予算設定前でも支出を登録できる。
- 初回利用時に今月の予算を未設定として確定する。後から過去月の予算を設定しても、今月へ自動反映しない。
- 利用開始より前の月も、その月より前に設定済みの月があれば最も新しい月から直接引き継ぎ、なければ未設定から始める。作成するのは操作対象月だけとし、間の月は作らない。
- 予算未設定と明示的な0円設定は区別して表示する。
- 費目別予算額は0円から2,147,483,647円まで設定できる。
- 一度設定した費目別予算は、未設定に戻せる。
- 予算編集画面では、金額を入力した費目だけをまとめて保存できる。保存対象の入力欄を空にした状態では保存できない。未設定に戻す場合は、費目ごとの「予算を削除」操作を使う。削除後は未設定として表示する。
- 「予算を削除」は確認ダイアログで確認してから実行する。金額0を保存した場合は、明示的な0円設定として扱う。
- 予算削除の確認画面には、対象月・費目名・現在の予算額を表示し、「未設定に戻す」と明示する。
- 月全体の予算額は、その月の費目別予算額の合計。未設定の費目は合計上0円として扱い、月全体の予算額を別には設定しない。
- 月全体の支出額には、予算未設定の費目も含め、すべての支出を合計する。
- 未分類の支出も月全体の支出額に含める。未分類には費目別予算を設定せず、費目別の残額も表示しない。
- 月全体の残額は「設定済み予算額の合計 − すべての支出額」とする。
- 費目別の残額は、予算額が設定されている費目について「予算額 − その費目の支出額」とする。予算未設定の費目には残額を表示しない。
- 予算を超えても支出を登録できる。超過額はアプリ内で分かるように表示し、プッシュ通知は出さない。
- 前月の費目別予算額を翌月へ引き継ぎ、必要な月だけ変更できる。使い残した金額は繰り越さない。
- 費目を非表示にした月までの予算額と集計結果は残す。その費目の予算額は翌月以降へ自動では引き継がない。
- 費目を再表示しても、非表示前の予算額は自動で復活しない。再表示した月に予算がなければ未設定とする。同じ月にすでに予算がある場合はその額を保持する。
- アプリを使わなかった月の予算データは作らない。数か月ぶりに再開した月は、それより前で最も新しい設定済み月の費目別予算額を直接引き継ぎ、再開した月だけを作る。
- 過去月の予算額を後から修正できる。ただし、すでに存在する後の月の予算額には反映しない。

## 画面と閲覧

- ログイン後は今月の予算・支出・残額と、費目別の状況を最初に表示する。
- そこから支出登録と支出明細の確認へ進める。
- 月を切り替えて過去月の予算と支出を閲覧できる。
- MVPでは未来月の予算を閲覧・編集しない。月が変わった後の最初の利用時に、その月より前で最も新しい初期化済み月から直接引き継ぐ。
- 過去月を閲覧するだけでは、その月の予算を新たに設定・確定しない。
- 予算データのない過去月を閲覧したときは、その月の予算を未設定と表示する。前月の額を確定済みの予算として表示しない。
- その過去月で予算編集を始めたときは、それより前で最も新しい設定済み月の予算額を入力欄の下書きとして示す。保存したときだけ対象月の予算として確定し、間の月は作らない。
- 予算編集は月単位で全費目をまとめて保存する。保存前の変更は保存操作まで確定しない。
- 月内の支出一覧を費目で絞り込める。「未分類」も絞り込み条件として選べる。
- MVPでは選択した1か月分の支出をまとめて読み込み、ページ分割は行わない。
- 支出一覧は支出日の新しい順で表示し、同じ日では登録時刻の新しい順にする。編集しただけでは同日の先頭へ移動しない。
- MVPではグラフを使わず、金額を中心に状況を示す。
- メモの文字検索はMVPに含めない。

## データ管理

- 支出データをCSVで書き出せるようにする。MVP内では実装優先順位を低くし、最後の方に対応する。

## 運用に関する要件

- 個人開発で維持できるよう、インフラの運用・保守作業と費用をできるだけ抑える。
- 長期間アクセスしなかっただけで、手動復旧が必要な状態になるサービスは避ける。
- 将来の家計共有や一般公開を検討する際に、技術的な制約と移行費用を評価できるようにする。

## MVP後の候補

- 優先して対応する: 定期支出の自動登録。
- その他: アカウントと家計簿データの削除、銀行連携による支出の自動取得、レシート読み取り、支払方法の記録、返金の独立した記録、メモ検索、グラフ、PC向けの表形式表示、家族利用や予算共有。
- ストア配信は必要になった時点で判断する。

## 次に決めること

- CSV書き出しの対象期間と列構成。
- 定期支出の自動登録など、MVP後の機能の詳細。
