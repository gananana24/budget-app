# 家計簿アプリ MVP要件

更新日: 2026-10-11

## 目的と利用者

- 毎月、何にいくら使ったかを、入力の負担を抑えて把握できるようにする。
- 初期の主な利用者は本人。公開後は、Googleアカウントを持つ他の利用者も登録できる。
- 利用者ごとの支出・カテゴリーは分離し、他の利用者には見せない。
- 家族による利用は将来想定するが、家計簿の共有はMVPに含めない。
- 課金と広告は導入しない。

## 提供形態

- iPhoneとAndroidのスマートフォンで使うWebアプリとして公開する。
- ホーム画面からアプリのように開けるPWAにする。PC向け画面はMVPの対象外。
- 利用にはオンライン接続を必要とする。オフラインでの支出登録は対象外。
- Googleアカウントでログインする。他のログイン方法はMVPでは提供しない。
- アカウントにデータを紐づけ、機種変更後も引き継げるようにする。
- 画面表示は日本語・英語・スペイン語に対応する。ログイン画面と設定画面で言語を切り替え、選択を端末に保存する。文言は多言語対応の仕組みで一元管理する。
- 通貨は日本円のみとし、金額は1円単位で扱う。
- 「今日」と「今月」は日本時間を基準にする。

## 支出の記録

- MVPで記録する取引は支出のみ。登録方法は手入力。
- 必須項目は日付・金額。カテゴリーとメモは任意。
- 支出額は1円から2,147,483,647円まで入力できる。
- メモは前後の空白を取り除いて保存し、500文字まで入力できる。空白だけの場合はメモなしとして扱う。
- 過去の日付で登録でき、支出はその日付が属する月に集計する。未来の日付では登録できない。
- 支出日の最古日は制限しない。有効な日付形式で、日本時間の今日以前なら登録できる。
- 同じ日・金額・カテゴリーの支出も複数登録できる。
- カテゴリーを選ばずに登録した支出は「未分類」として表示する。編集時にカテゴリーを設定したり、設定済みのカテゴリーを未分類へ戻したりできる。
- 登録済みの支出は、過去月のものも含めて修正・削除できる。
- 追加カテゴリーを削除しても既存の支出は残し、その支出のカテゴリーだけを未分類へ戻す。
- 修正前の内容を履歴として保存・表示する機能はMVPに含めない。
- 支出の削除前には確認を求める。削除した支出は集計やCSV書き出しの対象から外れる。
- 支払方法は記録しない。返金は独立した取引としては記録せず、元の支出の修正・削除で対応する。
- 家賃やサブスクなどの定期支出もMVPでは手入力する。

## カテゴリー

- 初期カテゴリーはアプリ全体で共有する「食費」「日用品」「住居費」「水道光熱費」「通信費」「交通費」「医療費」「娯楽費」「その他」の9つ。家計を作るたびに複製しない。
- 初期カテゴリー名は選択言語で表示し、追加カテゴリー名と支出メモは利用者の入力どおり表示する。
- 初期カテゴリーはアプリが管理し、利用者は名前を変更・削除できない。
- 利用者はカテゴリーを追加し、追加したカテゴリーの名前を変更・削除できる。
- 追加カテゴリーにはLucideのアイコンを選べる。選択したアイコンはカテゴリーに保存し、名前変更時にも選び直せる。初期カテゴリーは固定のアイコンを表示する。
- 新しく追加したカテゴリーは、そのカテゴリーを作る前の日付の支出にも使用できる。
- カテゴリー名は前後の空白を取り除いて保存し、1〜50文字とする。空白だけの名前は使えない。
- 同じ家計の中では、初期カテゴリーと追加したカテゴリーを通じて同じ名前を使えない。別々の家計では同じカテゴリー名を使える。
- 英字の大文字・小文字だけが違うカテゴリー名も、同じ家計内では同名として扱う。表示上の表記は入力どおり残す。
- 追加カテゴリーを削除した場合、そのカテゴリーを使っていた支出は削除せず未分類へ戻す。
- カテゴリーは初期の9件を記載順で表示し、追加したカテゴリーは追加順に続ける。名前変更で順番は変えず、MVPでは手動で並べ替えられない。
- カテゴリー名を変更すると、過去の支出に表示される名前も変わる。

## 月次集計

- 暦月の1日から末日までの支出を集計する。
- 月全体の支出額には、カテゴリー未設定の支出も含める。
- カテゴリー別の支出額を表示する。カテゴリー未設定の支出は「未分類」として表示する。
- 予算額の入力、残額、超過判定は提供しない。

## 画面と閲覧

- ログイン後は今月の支出合計と、カテゴリー別の内訳を最初に表示する。
- そこから支出登録と支出明細の確認へ進める。
- ホームは今月の支出合計を主役に、最近の支出3件と支出のあるカテゴリーの内訳を示す。支出画面は月名の両側の矢印で月を切り替え、選択月の支出合計と日付順の全記録を表示する。記録はカテゴリーで絞り込め、下部で支出のあるカテゴリーの内訳を確認できる。登録は独立した画面で行う。
- 月を切り替えて過去月の支出を閲覧できる。未来月へは移動しない。
- 月内の支出一覧をカテゴリーで絞り込める。「未分類」も絞り込み条件として選べる。
- MVPでは選択した1か月分の支出をまとめて読み込み、ページ分割は行わない。
- 支出一覧は支出日の新しい順で表示し、同じ日では登録時刻の新しい順にする。編集しただけでは同日の先頭へ移動しない。
- MVPではグラフを使わず、金額を中心に状況を示す。
- メモの文字検索はMVPに含めない。

## データ管理

- 支出データをCSVで書き出せるようにする。MVP内では実装優先順位を低くし、最後の方に対応する。

## 運用に関する要件

- 個人開発で維持できるよう、インフラの運用・保守作業と費用をできるだけ抑える。
- 長期間アクセスしなかっただけで、手動復旧が必要な状態になるサービスは避ける。
- 将来の家計共有や一般公開を検討する際に、技術的な制約と移行費用を評価できるようにする。

## MVP後の候補

- 優先して対応する: 定期支出の自動登録。
- その他: アカウントと家計簿データの削除、銀行連携による支出の自動取得、レシート読み取り、支払方法の記録、返金の独立した記録、メモ検索、グラフ、PC向けの表形式表示、家族利用。
- ストア配信は必要になった時点で判断する。

## 次に決めること

- CSV書き出しの対象期間と列構成。
- 定期支出の自動登録など、MVP後の機能の詳細。
