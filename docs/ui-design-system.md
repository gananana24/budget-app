# 家計簿アプリ UIデザインシステム

更新日: 2026-10-13

## 対象と方向性

スマートフォンで支出を手入力し、毎月の使い道を手早く確かめたい人のための画面。今月の支出額を主役にし、記録と内訳を迷わず辿れるようにする。情報の整理と余白の使い方は [catnoseさんの個人サイト](https://catnose.me/) と [本人によるサイト刷新の記事](https://catnose.me/notes/renewed) を参考にした。既存作品の見た目を複製しない。

## 色

| 用途 | 値 | 使用箇所 |
| --- | --- | --- |
| 背景 | `#F8FAF7` | 画面全体 |
| カード | `#FFFFFF` | 一覧、設定、入力 |
| 本文 | `#2B312D` | 見出し、金額、主要な文章 |
| 補助文字 | `#68706B` | 日付、説明 |
| 境界線 | `#E5E9E5` | カードと行の区切り |
| 主色 | `#27814E` | 主操作、選択状態、フォーカス |
| 補助面 | `#EFF1EE` | アイコン背景、選択前の補助操作 |
| 危険 | `#B43435` | 削除、入力エラー |

色だけで状態を伝えず、文字またはアイコンを併記する。主色をカテゴリーごとの意味付けには使わない。

## 文字と数字

- 英語・スペイン語と数字には Poppins、日本語の字形には Noto Sans JP Variable を使う。読み込み前や未収録の文字には端末のゴシック体を使う。
- 月合計は36〜45px、画面見出し24px、節見出し18px、本文16px、補助情報14pxを基本にする。
- 金額は等幅数字を使い、長い金額は320px幅でも折り返して読めるようにする。
- 英語・スペイン語の長い文言でも、主要操作が横方向にはみ出さないようにする。

## 余白と形

- 4px単位。画面左右24px、カード内20〜24px、項目間12〜16px、節間32〜40px。
- ボタンと入力は角丸12px、カードは20〜24px。立体感は強い影ではなく、薄い境界と面の違いで表す。
- 操作のタップ領域は最低44px。下部ナビゲーションはSafe Areaを含める。

## コンポーネントと画面

- **ボタン:** 主操作は深緑の塗りと白文字。ホームと支出画面では下部ナビゲーションの右上に56pxの円形鉛筆ボタンを固定し、片手で届きやすくする。支出がない状態では「支出を追加」の文字付きカプセルに広げる。内容がボタンの背後に隠れない余白を確保し、アイコンだけの状態にも読み上げ名を付ける。フォームでは高さ56pxの文字付き保存ボタンを使う。押下・フォーカス状態を示す。副操作は淡い中立色の面。削除は確認ダイアログを挟む。
- **入力:** ラベルを常時表示する。支出フォームは必須の金額・日付を先に、任意のカテゴリー・メモを後に置く。カテゴリーの任意表示を保ち、カテゴリー・言語・支出絞り込みの選択肢には十分な高さと余白を設ける。日付は shadcn/ui のカレンダーで選ぶ。金額欄を最も読みやすくし、エラーは欄の直下に表示する。入力枠はほかの画面と同じ淡い境界線でそろえる。
- **カード:** 月合計は白いカードで余白と大きな数字によって強調する。ホームの内訳はカードと見出しを付けず、チャートを中央に大きく置き、凡例を下へ縦に並べる。カテゴリー名と月額を一行で示し、金額は右揃え、長いカテゴリー名だけを省略表示する。支出一覧は白いカード内を細い線で区切る。
- **画面ヘッダー:** ホーム・支出・設定の3タブは同じ余白と24pxの画面名を使う。月切り替えは支出画面のヘッダー直下に置く。入力・編集画面は戻る操作と画面名を並べる。
- **支出画面:** 月名の両側の矢印で対象月を切り替え、直下に月全体の合計額を大きく置く。合計の説明ラベルは視覚的に省き、読み上げ名は残す。絞り込みはフィルターアイコンと選択中の名前を一つの欄で示し、操作にも読み上げ名を付ける。「すべて」を先頭に置き、ほかの選択肢は月額の多い順に並べる。選択中のカテゴリー名と金額を閉じた状態でも表示し、明細の絞り込みと内訳確認を一つの操作にする。明細のカテゴリーアイコンは残す。
- **ナビゲーション:** ホーム／支出／設定の3項目を本文のスクロール領域の外に置き、主要画面の下部に固定する。支出の新規入力・編集では下部ナビゲーションを隠し、ヘッダーの戻る操作を使う。アイコンと文字を併記し、現在地は主色で示す。本文の末尾は追加ボタンに隠れない余白を取る。
- **端末での操作感:** 下部タブの選択アイコンに淡い面を置き、タップ中の反応を見せる。画面本文は端末の慣性スクロールを使い、端でのスクロールをアプリ内に留める。ホーム画面起動時のシステムバーと起動画面はアプリ背景色に揃える。
- **アイコン:** Lucideを使い、通常20px、線幅は約1.8px。カテゴリー名や操作ラベルを省略しない。
- **初回利用:** 長い紹介画面は設けず、支出がない月には短い一言と曲線の矢印で右下の追加ボタンへ誘導する。記録後は案内を消し、月合計と一覧へ反映する。
- **サインイン:** アプリと同じ背景色・書体・深緑をClerkの認証UIにも適用する。カードの浮きをなくし、画面名と説明、Googleログインを中央に揃える。言語選択は画面下部に置き、入力とボタンは48px以上にする。
- **状態表示:** 全画面の読み込み・エラーは中央に置き、読み込み文言は短い「読み込み中」に統一する。画面内の空状態は内容の位置に合わせて表示する。

## 画面品質

緑は主操作と現在地など、行動を示す場所に絞る。ホームのドーナツチャートだけは同系色の濃淡を使い、12時方向から上位3カテゴリーと「その他」を示す。初期の「その他」カテゴリーも残りへ集約し、凡例の重複を避ける。中央には数値を置かない。高級感は余白、数字の整列、簡潔な文言、滑らかな反応で作る。MVPの課金機能と予算管理は追加しない。320px幅、文字拡大、キーボード操作、フォーカス表示、日本語・英語・スペイン語で確認する。
